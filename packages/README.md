# Umumiy paketlar

- `shared-types` — frontend va backend uchun umumiy turlar
- `api-client` — OpenAPI asosida generatsiya qilinadigan klient
- `ui` — umumiy UI komponentlar (shadcn/ui)
- `config` — eslint/tsconfig/prettier sozlamalari
- `validation` — umumiy validatsiya sxemalari

Paketlar kerak bo'lganda qo'shiladi.
